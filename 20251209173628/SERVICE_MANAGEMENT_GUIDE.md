# 服务管理功能使用指南

## 📊 概述

服务管理页面是MCP市场平台的核心管理界面，提供MCP服务的全生命周期管理、监控、测试和接入指南功能。

---

## 🎯 功能模块

### 1. 统计概览

位于页面顶部的四个统计卡片，实时展示关键指标：

| 指标 | 说明 | 颜色 |
|------|------|------|
| **服务总数** | 平台所有MCP服务数量 | 蓝色 🔵 |
| **今日调用** | 今天所有服务的累计调用次数 | 绿色 🟢 |
| **平均成功率** | 所有服务的平均成功率（100%-错误率） | 绿色 🟢 |
| **平均响应** | 所有服务的平均响应时间（毫秒） | 紫色 🟣 |

**成功率计算**：
```
成功率 = 100% - 错误率
```

---

### 2. 服务列表

展示所有MCP服务的详细信息，支持搜索和筛选。

#### 表格列说明

| 列名 | 说明 | 功能 |
|------|------|------|
| 服务名称 | MCP服务的名称 | 加粗显示 |
| 状态 | 运行状态 | 标签展示：运行中（绿）、测试中（黄）、已停用（灰） |
| 调用次数 | 累计调用次数 | 支持排序 |
| **成功率** | 服务调用成功率 | **≥99%绿色，≥95%黄色，<95%红色** |
| 平均响应 | 平均响应时间 | 支持排序 |
| 创建时间 | 服务创建日期 | - |
| 创建人 | 服务创建者 | - |
| 操作 | 操作按钮 | 详情、监控、测试、下线 |

#### 筛选功能
- **搜索框**：搜索服务名称或描述（实时过滤）
- **状态筛选**：全部状态 / 运行中 / 测试中 / 已停用

## 🔧 操作功能详解

### 3. 详情功能 📄

点击"详情"按钮，打开右侧抽屉，查看服务的完整配置和使用说明。

#### 3.1 服务配置标签页

**基础配置**
- 服务名称
- 服务描述
- 服务状态（标签展示）
- 创建时间
- 创建人

**密钥信息** 🔑
- **AppKey**：应用密钥，点击"复制"按钮一键复制
  ```
  格式：mcp_{serviceId}_app_key_demo
  ```
- **AppSecret**：应用密钥（安全显示为•••），点击"查看"联系管理员
- **API Endpoint**：服务接口地址，点击"复制"按钮一键复制
  ```
  格式：https://api.mcp-platform.com/v1/services/{serviceId}
  ```

**实体范围**
- 专辑筛选：显示专辑名称、描述、实体数量
- 规则筛选：显示自定义规则配置

**原子能力清单**
- 编号列表展示所有已配置的原子能力
- 每个能力显示序号和名称

#### 3.2 使用说明标签页

提供多种接入方式的详细指南，所有代码均可一键复制。

**方式一：CodeBuddy AI编程工具** 💻

1. **打开配置**
   ```
   Settings → MCP Servers → Add Server
   ```

2. **添加服务配置**（JSON格式，可复制）
   ```json
   {
     "name": "营销数据分析MCP",
     "type": "http",
     "url": "https://api.mcp-platform.com/v1/services/s1",
     "headers": {
       "X-AppKey": "mcp_s1_app_key_demo",
       "X-AppSecret": "your_secret_here"
     }
   }
   ```

3. **重启CodeBuddy生效**

**方式二：自定义Agent集成** 🤖

**HTTP API调用示例**（可复制）
```bash
POST https://api.mcp-platform.com/v1/services/s1/invoke
Content-Type: application/json
X-AppKey: mcp_s1_app_key_demo
X-AppSecret: your_secret_here

{
  "capability": "getTableSchema",
  "params": {
    "tableName": "user_info"
  }
}
```

**Python SDK示例**（可复制）
```python
from mcp_client import MCPClient

client = MCPClient(
    app_key="mcp_s1_app_key_demo",
    app_secret="your_secret_here"
)

result = client.invoke(
    service_id="s1",
    capability="getTableSchema",
    params={"tableName": "user_info"}
)
print(result)
```

### 4. 监控功能 📊

点击"监控"按钮，打开监控详情抽屉，查看服务运行状态。

#### 监控内容

**服务信息**
- 服务名称
- 服务描述

**关键指标**（3个卡片）
- 累计调用次数
- 错误率（红色 >1%，绿色 ≤1%）
- 平均响应时间

**调用趋势图**
- 折线图展示最近7天的趋势
- 三条曲线：
  - 调用量（蓝色）
  - 错误数（橙色）
  - 响应时间（绿色）
- 支持鼠标悬停查看详情

**最近调用日志**
- 时间：调用时间
- 用户：调用用户
- 状态：成功（绿）/ 失败（红）
- 耗时：响应时间

### 5. 测试功能 🧪

点击"测试"按钮，打开测试对话窗口，实时测试MCP服务。

#### 测试界面

**对话区域**
- 用户消息：蓝色背景，右对齐
- 服务响应：白色背景，左对齐
- 加载状态：显示"正在处理..."

**输入区域**
- 多行文本输入框（自动高度2-4行）
- 发送按钮（蓝色主按钮）
- 快捷键：回车发送，Shift+回车换行

#### 测试流程

1. **输入测试消息**
   ```
   示例：查询user_info表的结构
   ```

2. **发送消息**
   - 点击"发送"按钮
   - 或按回车键

3. **查看响应**
   - 模拟MCP服务的返回结果
   - 显示服务名称、调用能力数、响应时间

4. **多轮对话**
   - 继续输入新消息
   - 支持多轮测试

**模拟响应示例**：
```
已收到您的测试消息："查询user_info表的结构"。

这是模拟的MCP服务响应。实际环境中，这里会调用真实的服务接口，
基于已配置的实体范围和原子能力返回相应的数据。

服务名称：营销数据分析MCP
调用能力：4个
响应时间：85ms
```

### 6. 下线功能 ⚠️

点击"下线"按钮，停用MCP服务。

#### 确认流程

1. **点击下线按钮**（红色危险样式）

2. **确认弹窗**
   - 标题："确认下线"
   - 内容："确定要下线服务「XXX」吗？下线后将无法继续调用。"
   - 按钮："确认下线"（红色） / "取消"（灰色）

3. **下线成功**
   - 提示："服务已下线"

**注意**：下线后服务将无法继续被调用，请谨慎操作！

## ❓ 常见问题

### Q1：如何获取AppSecret？
**A**：点击详情 → 服务配置 → 密钥信息 → 点击"查看"按钮，按提示联系管理员获取。

### Q2：测试功能是真实调用吗？
**A**：当前是模拟响应，展示服务的基本信息。实际环境中会调用真实的MCP服务接口。

### Q3：下线服务后能恢复吗？
**A**：下线后服务状态变为"已停用"，可以通过编辑功能重新启用（该功能待开发）。

### Q4：成功率如何计算？
**A**：成功率 = 100% - 错误率。例如错误率0.5%，则成功率为99.5%。

### Q5：为什么复制按钮没反应？
**A**：请确保浏览器允许剪贴板权限。复制成功后会显示"已复制到剪贴板"提示。

## 🚀 快速开始

### 场景1：接入CodeBuddy

```
1. 服务管理 → 找到目标服务 → 点击"详情"
2. 切换到"使用说明"标签
3. 找到"方式一：CodeBuddy AI编程工具"
4. 点击"复制配置"按钮
5. 打开CodeBuddy Settings → MCP Servers → Add Server
6. 粘贴配置，填写真实的AppSecret
7. 重启CodeBuddy
```

### 场景2：Python项目集成

```
1. 服务管理 → 找到目标服务 → 点击"详情"
2. 切换到"使用说明"标签
3. 找到"Python SDK示例"
4. 点击"复制代码"按钮
5. 粘贴到你的Python项目
6. 替换AppKey和AppSecret
7. 运行测试
```

### 场景3：服务测试验证

```
1. 服务管理 → 找到目标服务 → 点击"测试"
2. 输入测试消息："查询user_info表的结构"
3. 点击"发送"或按回车
4. 查看服务响应
5. 继续测试其他场景
6. 关闭测试窗口
```
