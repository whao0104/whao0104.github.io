# MCP市场 - 元数据管理平台

## 项目简介

这是一个基于大数据平台元数据管理模块构建的**MCP市场能力管理系统**。通过将元数据的原子能力（如表结构查询、血缘分析、指标计算等）封装为可复用的服务组件，支持用户按需组装、定制和管理专属的MCP（Model Context Protocol）服务。

## 核心功能

### 1. 服务市场 🛒
- **能力展示**：以卡片式布局展示12+元数据原子能力
  - 表类能力：获取表结构、表血缘、字段血缘、统计信息等
  - 指标类能力：获取指标定义、指标血缘、指标趋势等
  - 看板类能力：获取看板配置、看板数据等
- **搜索筛选**：支持按能力名称、类型、分类等多维度筛选
- **详情查看**：查看能力详细信息、API示例和调用统计

### 2. MCP工坊 🔧

#### 快速生成模式
- 提供4个预设模板：
  - 💻 数据开发助手
  - 🛡️ 数据治理顾问
  - 📊 指标分析专家
  - 📈 可视化看板管家
- 选择模板后可配置服务信息和实体范围
- 支持预览配置后一键生成MCP服务

#### 精细化选择模式
- **可视化画布**：基于ReactFlow的拖拽式编辑器
- **原子能力库**：按分类展示所有可用能力
- **节点连接**：支持连线表示能力间的依赖关系
- **节点详情**：点击节点查看详细信息
- **实时配置**：右侧配置面板同步编辑MCP服务参数

### 3. 实体范围配置 🎯

支持两种筛选模式：

#### 规则筛选
- 数据库选择
- 表名正则匹配
- 标签多选
- 热度阈值设置
- 业务域筛选
- 实时预览匹配结果

#### 专辑筛选
- 从预定义的数据专辑中选择：
  - 🎯 营销域核心表（45个实体）
  - 💰 财务指标集（28个实体）
  - 👥 用户行为表（62个实体）
  - 📊 运营看板集（18个实体）

### 4. 服务管理 ⚙️

#### 概览统计
- 服务总数
- 今日调用量
- 活跃用户数
- 平均响应时长

#### 服务列表
- 支持搜索和状态筛选
- 显示调用次数、错误率、响应时间等指标
- 提供编辑、监控、权限、下线等操作

#### 监控详情
- 最近7天调用趋势图表（基于ECharts）
- 实时统计指标展示
- 调用日志列表

#### 权限管理
- 用户授权配置（基于Transfer组件）
- 支持批量授权

## 核心功能演示

### 服务市场
1. 浏览12+元数据原子能力卡片
2. 使用搜索框和筛选器查找能力
3. 点击卡片查看详细信息和API示例
4. 查看能力的调用统计和性能指标

### MCP工坊 - 快速生成
1. 从左侧选择一个预设模板
2. 右侧自动填充模板的配置信息
3. 点击"配置范围"设置实体筛选规则或选择专辑
4. 点击"预览配置"查看完整配置
5. 确认后生成MCP服务

### MCP工坊 - 精细化选择
1. 从左侧工具面板拖拽或点击添加能力节点到画布
2. 连接节点表示能力间的依赖关系
3. 点击节点查看详细信息
4. 在右侧配置面板填写MCP服务信息
5. 点击"配置实体范围"设置筛选条件
6. 保存并生成MCP服务

### 服务管理
1. 查看服务列表和统计概览
2. 使用搜索和筛选功能定位服务
3. 点击"监控"查看服务调用趋势和日志
4. 点击"权限"配置用户访问权限
5. 点击"下线"停用服务
